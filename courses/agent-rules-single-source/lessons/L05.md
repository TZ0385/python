# Apply this to your repository

## Objective

One AGENTS.md, thin pointers everywhere else, and a failing check when it breaks.

## The lesson

In your own repository: write (or prune) AGENTS.md as the single rule source, replace every other rule file with a thin pointer, add rules_check.py and its test line to CI. The workflow is the product; the checker is just the guardrail.

## Exercise

- Run the checker from a clean checkout to prove it does not depend on your machine

## Checkpoint

The lesson's commands run, and you can explain — in your own words — what failed and why.

## Expected evidence

The command transcript and your answers.
