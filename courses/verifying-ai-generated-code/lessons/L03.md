# Build the ship check, test by test

## Objective

Parsing, verdicts, the unverified list, atomic writes, exit codes — one failing group at a time.

## The lesson

Tell the agent: "Work through TASK.md against starter/ship_check.py, one failing test group at a time: parsing, then verdicts, then the unverified list, then atomic writes, then CLI exit codes. Show me the diff after each group."

## Exercise

- Run PYTHONPATH=starter python -m unittest discover -s tests -v after each group
- Never let a change weaken a verdict to make a test pass

## Checkpoint

The lesson's commands run, and you can explain — in your own words — what failed and why.

## Expected evidence

The command transcript and your answers.
