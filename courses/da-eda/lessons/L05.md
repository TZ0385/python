# Challenge 05: Run it on your own data

**Gate:** self-attested · **Points:** 10

Take a real export you have — an order sheet, a usage log, a bank CSV —
and run the same load → clean → summarize pipeline on it. The point is
not the code porting cleanly (it won't); it is discovering which
assumptions break: column names, encodings, date formats, currencies.

**Checkpoint:** you can name one assumption from this course's dataset
that did *not* hold on your real data. Self-attested; record via
`python verify.py progress`.
