# 模块 0：Agent 工具生态总览

**积分：** 10 · **类型：** 入门导览 · **证据：** 自我声明

在动手课程之前先搞清楚地形：有哪些工具、它们的共性是什么、你先驱动哪一个。

## 生态概览

这条路线里有三个重要的 Agentic 编程工具：

| 工具 | 运行位置 | 擅长什么 |
| --- | --- | --- |
| **Claude Code** | 终端 | 长链路多步任务，指令遵循强，读 `CLAUDE.md`/`AGENTS.md` |
| **Codex CLI** | 终端 | 开源 Agent 循环，沙箱执行，读 `AGENTS.md` |
| **Cursor** | IDE | 编辑器内嵌改写与对话，适合习惯 GUI 的人 |

它们的差别在界面，不在本质。每一个都：读你的文件、遵循书面指令、改代码、
跑命令，以及——这是重点——**可能以一种看起来对的方式出错**。所以这条
路线把大量精力放在规则和验证上，而不是提示词上。

## 你的第一个任务（不写代码）

1. 在 Claude Code 或 Codex CLI 里**选一个**，按官方文档装好（课程页有链接）。
2. 在一个空文件夹里打开终端，启动 Agent，对它说：
   “写一个打印当前日期的 Python 脚本，然后运行它。”
3. 观察它的行为：建了哪些文件、跑了哪些命令、汇报了什么。
4. 问它：“你怎么知道它能跑？”——注意它是**给出证据**还是**只说能跑**。
   这个差距就是这条路线剩下部分要解决的问题。

## 检查点

当你能用自己的话回答下面两个问题时，本模块完成：

- 你装了哪个 Agent，怎么启动它？
- 当你要日期脚本时它做了什么——它给出的“脚本跑通了”的证据是什么？

自我声明检查点：两个问题都能答上，就记录下来——基础路线 M0 模块值
10 分。诚实自报是本平台的规则：没人检查你的答案，但这里的一切也都
不是证书。
